## 🏗️ 系统概述

这是一个**六脉统一的母系统**——六个 Agent（天道·战略、地利·产品、人和·模式、神韵·内容、财帛·转化、法度·风控）在一个平台上贯通运作，底层接入**八字命理**与**MBTI人格**分析引擎，实现天命+人性+商业的三合一诊断。

```
客户企业
    ↓
【前端成交】— 你亲自谈客户、做诊断、定战略
    ↓
【执行核心】— 六脉蜂群系统（AI智能中台）
    ├── 战略分析
    ├── Agent协同
    └── 商业决策
    ↓
【客户产出】— IP内容持续产出、团队运行、商业模式验证
```

### 系统概览

| 属性 | 内容 |
|:--|:--|
| **仓库** | [天道六脉系统](https://github.com/211985lxy/ai-business-growth-os) |
| **技术栈** | Next.js 16 + React 19 + TypeScript 5 + Tailwind 4 |
| **后端** | Supabase（认证 + 数据库 + 实时） |
| **AI引擎** | Dify（六脉 Agent 工作流编排） |
| **部署** | Vercel / 自托管 |

**核心功能：**
- **Queen Agent** — 智能任务分解与多 Agent 协同
- **命理诊断引擎** — 接入八字排盘+紫微斗数，辅助创始人判断趋势时机与战略节奏
- **MBTI人格透视** — 识别创始人/核心团队的性格模式，匹配合适的战略路径与组织架构
- **六脉 Agent 矩阵** — 天道·战略 / 地利·产品 / 人和·模式 / 神韵·内容 / 财帛·转化 / 法度·风控
- **Swarm Memory** — 跨 Agent 上下文共享（Redis）
- **Workplace 三栏布局** — 左侧输入 → 中间过程可见 → 右侧流式输出
- **主动追问引擎** — 信息不足时自动追问，拒绝碎片化回答

**段永平读巴菲特演讲十遍总结的六大投资智慧，我用来选客户：**

| 段永平原则 | 投资翻译 | 我的客户筛选 |

## 📦 交付 SOP：3 个月企业数字神经系统搭建

基于老葛实战案例还原的标准化交付流程：

| 阶段 | 周期 | 核心交付 | 关键产出 |
|:--|:--|:--|:--|
| Phase 1 · 入局诊断 | 第 1-2 周 | 创始人访谈 + 团队摸排 + 行业数据 | 诊断报告（一页纸） |
| Phase 2 · 战略定向 | 第 2-3 周 | 商业模式梳理 + 战略路径确认 | 战略蓝图（一页图） |
| Phase 3 · 思想统一 | 第 3-4 周 | 团队培训（毛选思维）+ 组织共识搭建 | 培训课件 + 组织 SOP |
| Phase 4 · 系统落地 | 第 5-8 周 | **六脉蜂群 AI 中台** 部署上线 | 全链路上线 |
| Phase 5 · 运行陪跑 | 第 9-16 周 | 内容生产跑通 + 数据复盘 + 流程优化 | 运营数据报告 |
| Phase 6 · 知识转移 | 第 17 周起 | 团队独立运营 + 降级为月度陪跑 | 交接手册 |

**Phase 4 关键动作：** 六脉蜂群 AI 中台正式上线，覆盖战略分析、内容生成、发布追踪等环节，形成"战略→内容→效果"的完整闭环。
